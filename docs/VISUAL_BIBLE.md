# Orbital Salvage — visual bible

## Direction

Compact arcade salvage run in a dark-purple orbit. The scene uses one restrained
Kenney space family with a cyan/blue interface and warm amber salvage accents.
The first sector is a single readable playfield rather than a busy procedural world.

## Readability rules

- Station is the strongest landmark: bright blue ring, warm core, and a dedicated glow.
- Player ship is a small cool-white/cyan silhouette with a visible exhaust flicker.
- Scrap is warm amber/yellow with a circular glow and is never the same silhouette as debris.
- Moving debris is muted brown/gray and larger, so it reads as danger before contact.
- The background is dark purple with a very subtle haze layer; it must never compete with gameplay.
- HUD is compact, all-caps, and uses the Kenney Future font with blue panels and cyan text.
- No debug rectangles, editor chrome, placeholder labels, or prototype-only controls in the play view.

## Color intent

- Space: deep purple / near-black.
- Safe systems: cyan and electric blue.
- Salvage: amber and pale gold.
- Danger: muted orange-red only for hit feedback and shield loss.
- Result state: brighter cyan/white against a dimmed playfield.
