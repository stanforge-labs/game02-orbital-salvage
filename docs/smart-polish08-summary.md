# Smart Gameplay Polish 08 — проверка

## Ограниченный объём

Исправлены пять групп проблем: слишком короткие маршруты/контракты; раннее
открытие второго сектора; крупные примитивные обломки; загрузка шрифта и
расположение подписей; взаимодействие мыши, награды и полезность модулей.
Новая механика только одна: серия подбора без столкновений (+5 за третий,
+10 за пятый предмет). Бонус теряется вместе с недоставленной добычей.
Камера, сохранения и рекламный адаптер не переписаны.

## Естественное прохождение

`smart-polish08-report.json` записан из чистого браузерного профиля реальными
нажатиями клавиш и кликами. Нет начальных кредитов, телепорта, подмены HP,
счётчика вылетов или разблокировки сектора. Скрипт знает координаты маршрута:
это автоматизированный опытный игрок, не замер поведения незнакомого с игрой человека.

Первый лом — 4,5 с; первый возврат — 68,9 с; первое улучшение — около 128 с;
второе — 199,4 с; первая технодеталь — 198,6 с; сектор 2 открыт на 253 с,
вход — 254 с; полный маршрут с возвратом — 319,8 с. Точные значения в JSON.
Пять успешных контрактов; корпус после последнего возврата 3/4.

Предыдущая попытка прямого возвращения через опасный карман закончилась гибелью.
Финальная попытка использовала южный обход с обычным управлением. Опасность
не отключалась. Это подтверждает значение выбора маршрута, но не гарантирует
выживание при любом пути. Отдельный безопасный маршрут контракта «Опасный сбор»
прошёл за 66,8 с с одним повреждением.

## Отдельные регрессии

`smart-polish08-checks.json` и `smart-polish08-contract-checks.json` используют
явно помеченные тестовые сохранения и не входят в естественный тайминг.

- Трюм: реальный HUD следующего вылета 0/10; корпус: 4/4.
- Двигатель: измерено 190 → 209, ровно +10%.
- Магнит: расстояние подбора 91,66 → 112,25 единицы при дискретном опросе.
- Радар: реальный текст HUD содержит время возвращения и стоимость цели.
- Сброс четырёх модулей: базовые 8/3/0/0, возврат 502 из 670 кредитов (75%, вниз).
- Обновление меняет предложения; если весь оставшийся пул уже показан,
  технодеталь не расходуется.
- Страховка выплачивает компенсацию, второй шанс возвращает корабль к станции.
- Hover/pressed меняют изображение; движение мыши без нажатия не ведёт корабль.
- Локальное удвоение добычи выдаётся один раз; бесплатное рекламное обновление
  не тратит технодетали; сохранение переживает reload.
- Быстрый возврат с одним предметом не закрывает контракты скорости/без урона.

Камера: 1197 строк в `camera-trace-smart08.csv`; X 480…953,344;
Y 284,611…677; max |ΔX| 5,211, max |ΔY| 3,295 за кадр.
Проверены D/A, W/S, обратные переключения, диагональ и стрелки.

JSON валиден; сцена r/v/b = 0/0/0; отсутствующих ресурсов 0;
неизвестных экземпляров 0; некорректных цветов 0; три существующих JS-блока
проходят синтаксический разбор. Объектов 92, экземпляров 218, ресурсов 41.

GUI установленного GDevelop не проверялся. Реклама проверена только заглушкой,
не настоящей рекламной сетью Яндекса.
