# Космический сборщик — Game #2

Два сектора для Яндекс Игр: увеличенный мир, корабль-сборщик, станция,
варианты металлического лома, редкий контейнер, опасные обломки, трюм,
миссии, технодетали, модули корабля, rewarded-сценарии и локальный прогресс.

## Проект

- GDevelop 5.6.281: game.json;
- локальный экспорт: exports/smart-polish08/;
- рабочий путь: C:\Yandex Games\02 Orbital Salvage\.
- репозиторий: https://github.com/stanforge-labs/game02-orbital-salvage;
- текущий статус: русская версия, первый сектор и открываемый сектор 2,
  миссии, шесть улучшений и локальные rewarded-ad заглушки.

## Локальный запуск

Из каталога проекта запустить:

PowerShell -ExecutionPolicy Bypass -File .\scripts\export-core.ps1 -OutputDirectory exports/smart-polish08
python -m http.server 4173 --bind 127.0.0.1 --directory .\exports\smart-polish08

Открыть http://127.0.0.1:4173/index.html.

## Управление

- ПК: стрелки или WASD-совместимое управление через слой движения;
- мобильный горизонтальный экран: удержание и ведение пальцем от корабля;
- старт: кнопка, пробел или Enter; следующий вылет и повтор — кнопки;
- портретный экран: поверните устройство в горизонтальный режим.

## Текущий функциональный объём

- контракты: металлолом, контейнер, два контейнера, четыре единицы груза без
  повреждений, скоростная доставка и сбор внутри опасной зоны;
- карта 6200×3000: ближняя, рабочая и дальняя области; сектор 2 открывается
  после четырёх контрактов и двух установленных модулей;
- серия без столкновений: +5 за третий и +10 за пятый предмет; бонус нужно
  довезти до станции;
- улучшения: трюм, двигатель, корпус, магнит, радар и страховка;
- мета-решения: технодетали, обновление пула и сброс модулей;
- rewarded-сценарии: удвоение награды, второй шанс и бесплатное обновление пула
  на localhost через безопасную заглушку.

Платное обновление предложений стоит одну технодеталь; бесплатное требует
явного нажатия рекламной кнопки. Сброс с подтверждением возвращает 75% расходов.
Существующие сохранения читаются прежним ключом `orbitalSalvageSave`.

## Воспроизведение текущего pass

`node scripts/smart08-layout.js` и `node scripts/update-runtime-feature.js`
обновляют исходный проект. Баланс и маршруты: `scripts/smart08-config.js`.
После экспорта на localhost: `node scripts/smart08-qa.js` — настоящее прохождение;
`node scripts/smart08-checks.js` и `node scripts/smart08-contract-checks.js` — отдельные регрессионные проверки с явно
помеченными тестовыми сохранениями. Отчёты находятся в `docs/`, актуальные кадры
в `screenshots/SmartPolish08/`.

## Граница локального pass

Экспорт подключает официальный Yandex `/sdk.js` только на домене платформы;
физический SDK не хранится в проекте. На localhost rewarded ads используют
безопасную debug-заглушку. Облачное сохранение, дополнительные сектора,
достижения и таблицы лидеров пока не подключены. Английская локализация
отложена до утверждения русской версии.
