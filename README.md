# Космический сборщик — Game #2

Первый сектор для Яндекс Игр: один увеличенный мир, корабль-сборщик, станция,
варианты металлического лома, редкий контейнер, опасные обломки, трюм,
возврат, результат и минимальный экран улучшений.

## Проект

- GDevelop 5.6.281: game.json;
- локальный экспорт: exports/core-playable/;
- рабочий путь: C:\Yandex Games\02 Orbital Salvage\.
- репозиторий: https://github.com/stanforge-labs/game02-orbital-salvage;
- текущий статус: первый сектор, русская версия, CorePass02.

## Локальный запуск

Из каталога проекта запустить:

PowerShell -ExecutionPolicy Bypass -File .\scripts\export-core.ps1
python -m http.server 4173 --bind 127.0.0.1 --directory .\exports\core-playable

Открыть http://127.0.0.1:4173/index.html.

## Управление

- ПК: стрелки или WASD-совместимое управление через слой движения;
- мобильный горизонтальный экран: удержание и ведение пальцем от корабля;
- старт и следующий вылет: кнопка, пробел или Enter;
- повтор после повреждения: кнопка, пробел, Enter или R;
- портретный экран: поверните устройство в горизонтальный режим.
