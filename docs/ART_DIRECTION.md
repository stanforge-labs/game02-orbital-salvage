# World20 art direction

## Visual hierarchy

Ship and interactive salvage retain their established scale, cyan/white edges
and warm resource accents. Environment uses desaturated blue steel, dark solar
cells, recessed machinery and restrained edge highlights. No decorative pulse,
reward outline or extra damage collider.

Scenes have a dominant structure plus attached or broken secondary parts:
split habitat, repair dock, cruiser break, satellite collision, cargo spine,
fuel refinery, reactor shell, engine wreck, solar farm, tank gantry, broken
observatory, torn ring, transport grave, empty drydock, relay pair, anomaly cage.

## Regional palettes

| Region | Dominant construction language |
|---|---|
| Working orbit | Repair hardware, solar maintenance, tank gantries |
| Repair dock | Open docking forks, serviced habitats |
| Debris field | Split hulls, exposed rings, transport fragments |
| Satellite graveyard | Broken panel assemblies, damaged observation dishes |
| Meteor stream | Struck transport sections around existing moving hazards |
| Container trail / caravan | Cargo spines, separated transport structures |
| Radiation pocket | Reactor shells, fuel machinery, containment remnants |
| Cruiser rift | Engine blocks, split warship hulls |
| Ghost station | Broken habitation rings, empty service docks |
| Sensor anomaly / remote | Cages, damaged instruments, unusual radial layout |
| Relay region | Radio pairs, solar power arrays |
| Ore / energy | Industrial tanks, refinery and damaged power systems |
| Secret | Existing dedicated secret art and six safe pockets retained |

## Library counts, without inflated totals

16 large authored compositions; 24 medium variants from eight component
assemblies × three damage arrangements; 30 small variants from ten fragment
types × three orientations. These are 70 original SVG files, not 70 independent
gameplay systems. Source: `scripts/world20-art.js`; manifest:
`assets/game/world20/manifest.json`.

  REFERENCE ONLY; CC0, visually inspected modular solar/radio silhouettes.
- [Space Shooter Remastered](https://kenney.nl/assets/space-shooter-remastered):
  REFERENCE ONLY; CC0, consistent interactive-object hierarchy.
- [Space Station Kit](https://kenney.nl/assets/space-station-kit): REFERENCE ONLY;
  CC0, interior/3D orientation not appropriate for direct import here.
- [Wenrexa Space Modular Buildings](https://wenrexa.itch.io/space-full-assets-pack):
  REFERENCE ONLY; page explicitly permits commercial/free use without attribution;
  visually inspected. Rich modular shapes, but rendered style differs from game.
- [ChaosShark Shipyard](https://opengameart.org/content/sci-fi-top-down-shipyard-space-station):
  REFERENCE ONLY; CC0, open docking-space composition, pixel rendering differs.
- [ChaosShark Centrifuge](https://opengameart.org/content/sci-fi-top-down-centrifuge-space-station):
  REFERENCE ONLY; CC0, radial station identity, pixel rendering differs.

Focused CC0 searches also found unrelated 3D mega-kits and non-CC0 debris packs;
REJECTED for direct import: no need for dependencies, style mismatch or different
licensing. Nothing was downloaded and silently assumed commercial-safe.
