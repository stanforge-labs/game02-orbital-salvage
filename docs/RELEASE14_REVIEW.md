# Full Release Rebuild 14 — проверенный объём

## DONE

- Убраны параллельные обработчики старой и процедурной добычи, опасностей,
  секретного события и покупок. Один клик списывает стоимость одного модуля.
- Метеоры используют шесть фиксированных кадров; наследованная анимация больше
  не меняет размер и силуэт объекта каждый кадр.
- Корабль 46 → 32 logical px (−30,4%). Физика ускорения, управление камерой и
  обычный follow не переписаны. Радиусы подбора/опасностей согласованы с размером.
- Настоящая DeliveredValue выводится на результате вместо устаревших тарифов.
  Пустой возврат имеет нейтральный заголовок.
- Сохранённые предложения восстанавливаются после инициализации модулей.
- Одиннадцать покупок и reset проверены отдельным тестом: расходы 1940,
  возврат 1455 (75%), CargoMax 10→8, HullMax 4→3, Engine/Magnet 1→0.
- Секретный маршрут имеет физические переборки, шесть безопасных карманов,
  аппаратные излучатели и фазовый цикл лазеров. Кэш выдаётся один раз.
- Исправлены затемнение модалок, ресурсный виджет, кнопка гибели, всплывающий
  текст и положение предупреждения метеоров. Отсутствие модулей — отдельное
  завершённое состояние, без фиктивных пустых карточек.

## PARTIAL — не выдавать за полный release acceptance

- 12 базовых типов регионов имеют по два варианта размещения добычи (24
  комбинации), но это не 24 уникальные авторские геометрии. Chunk-streaming
  не создавался; используется существующий фиксированный пул видимых объектов.
- Четыре порядка проходов секретного маршрута используют общую топологию.
  Двойные/тройные/перекрёстные лазерные паттерны не реализованы.
- Визуальный язык ретранслятора и портала остаётся простым. Некоторые зоны
  всё ещё похожи друг на друга; коммерческое качество всех кадров не подтверждено.
- Все 14 типов контрактов не пройдены естественным образом по отдельности.
- Два обычных маршрута проверяют progression, ключ, шлюз, шесть карманов,
  кэш, возврат и повторную загрузку. Пять дополнительных seed проверены на
  геометрию карманов, а не пятью полными естественными прохождениями.
- Touch отправлялся в эмуляции; физический Android и полноценный touch-маршрут
  секретного события не проверялись.
- Yandex проверен только через localhost rewarded fallback, не production ads.
- Ранний темп остаётся слишком быстрым: первая покупка через 22,641 / 17,230 с,
  вход в Sector 2 через 86,228 / 69,458 с. Длинный интерес ещё не доказан.

## PERFORMANCE

Сравнение по 15 секунд в плотной области: p50 16,7 мс и p95 17,1 мс до/после.
JS heap 30,26 → 37,03 MB; число предварительно созданных экземпляров выросло
558→643. Это короткий smoke-замер, не доказательство отсутствия утечек.
Пул ограничен; лишние данные добычи обрезаются по реальной ёмкости пула,
чтобы не существовало невидимых игровых объектов без спрайтов.
