# Космический сборщик — Game #2

Первый сектор для Яндекс Игр: один увеличенный мир, корабль-сборщик, станция,
варианты металлического лома, редкий контейнер, опасные обломки, трюм,
миссии, технодетали, модули корабля, rewarded-сценарии и локальный прогресс.

## Проект

- GDevelop 5.6.281: game.json;
- локальный экспорт: exports/release-polish06/;
- рабочий путь: C:\Yandex Games\02 Orbital Salvage\.
- репозиторий: https://github.com/stanforge-labs/game02-orbital-salvage;
- текущий статус: русская версия, первый сектор и открываемый сектор 2,
  миссии, шесть улучшений и локальные rewarded-ad заглушки.

## Локальный запуск

Из каталога проекта запустить:

PowerShell -ExecutionPolicy Bypass -File .\scripts\export-core.ps1
python -m http.server 4173 --bind 127.0.0.1 --directory .\exports\core-playable

Открыть http://127.0.0.1:4173/index.html.

## Управление

- ПК: стрелки или WASD-совместимое управление через слой движения;
- мобильный горизонтальный экран: удержание и ведение пальцем от корабля;
- старт и следующий вылет: кнопка, пробел или Enter;
- повтор после повреждения: кнопка, пробел, Enter или R;
- портретный экран: поверните устройство в горизонтальный режим.

## Текущий функциональный объём

- миссии: сбор лома, доставка контейнера и вылет без повреждений;
- улучшения: трюм, двигатель, корпус, магнит, радар и страховка;
- мета-решения: технодетали, обновление пула и сброс модулей;
- rewarded-сценарии: удвоение награды, второй шанс и бесплатное обновление пула
  на localhost через безопасную заглушку.

## Граница локального pass

Экспорт подключает официальный Yandex `/sdk.js` только на домене платформы;
физический SDK не хранится в проекте. На localhost rewarded ads используют
безопасную debug-заглушку. Облачное сохранение, дополнительные сектора,
достижения и таблицы лидеров пока не подключены. Английская локализация
отложена до утверждения русской версии.
