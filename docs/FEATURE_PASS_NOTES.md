# Космический сборщик — текущий игровой pass

Проект собран в GDevelop 5.6 под HTML5/Yandex Games. Интерфейс и игровой текст
сейчас только на русском языке.

В текущей версии есть короткие миссии, технодетали, дополнительные модули
«Магнит», «Радар» и «Страховка», сброс модулей и обновление пула улучшений.
После успешной доставки игрок получает технодетали, а доставка контейнера даёт
дополнительную деталь. На локальном адресе рекламные награды работают через
безопасную отладочную заглушку; на домене Yandex Games используется официальный
`/sdk.js` и единый `YaGames.init()` из экспортного шаблона.

Физический `sdk.js` в проект и ZIP не включается.
